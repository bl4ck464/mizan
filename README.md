# ⚖️ Mizan

### Moroccan Finance & Banking Toolkit

Mizan is a lightweight, privacy-friendly financial calculator designed to make everyday financial calculations simple, fast, and accessible.

Built with plain HTML, CSS, and JavaScript, Mizan runs directly in the browser and is designed to work offline as a Progressive Web App (PWA).

---

## ✨ Features

### 🏦 Banking

- 💳 Loan payment calculator
- 📊 Debt ratio calculator
- 💰 Borrowing capacity calculator
- 🔄 Early repayment calculator
- ⚖️ Loan comparison

### 🌍 Localization

- 🇬🇧 English
- 🇫🇷 Français
- 🇲🇦 العربية
- Moroccan Dirham (MAD) support
- RTL support for Arabic

### 🎨 User Experience

- 📱 Responsive mobile design
- 💻 Desktop-friendly interface
- 🌙 Dark mode
- ☀️ Light mode
- ⚡ Fast client-side calculations
- 🔒 No account required
- 🌐 No server required for calculations

### 📲 Progressive Web App

Mizan is designed as a Progressive Web App.

Once installed, users can launch Mizan like a normal application and use its core calculators without an internet connection.

---

## 🧮 Calculators

### Loan Payment

Calculate:

- Monthly payment
- Total repayment
- Total interest

### Debt Ratio

Calculate the relationship between:

- Monthly income
- Existing debt
- New loan payment

### Borrowing Capacity

Estimate a possible loan amount based on:

- Income
- Desired debt ratio
- Interest rate
- Loan duration

### Early Repayment

Estimate:

- Remaining interest
- Remaining repayment cost
- Potential savings from early repayment

### Loan Comparison

Compare two financing scenarios based on:

- Loan amount
- Interest rate
- Duration
- Monthly payment
- Total repayment
- Total interest

## 🛠️ Technology

Mizan intentionally uses a simple technology stack.

| Technology | Purpose |
|---|---|
| HTML5 | Application structure |
| CSS3 | Responsive interface |
| JavaScript | Calculations & application logic |
| Web App Manifest | PWA installation |
| Service Worker | Offline functionality |
| LocalStorage | Local preferences |

No framework is required.

No backend is required for the core application.
